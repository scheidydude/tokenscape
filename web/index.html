How do I make the zip?

Claude Code

  • macOS / Linux: cd ~/.claude && zip -r ~/claude-sessions.zip projects
  • Windows: right-click %USERPROFILE%\.claude\projects → Send to → Compressed (zipped) folder
  • With the CLI installed: tokenscape bundle

Codex CLI

  • macOS / Linux: cd ~/.codex && zip -r ~/codex-sessions.zip sessions
  • Windows: right-click %USERPROFILE%\.codex\sessions → Send to → Compressed (zipped) folder
  • With the CLI installed: tokenscape --tool codex bundle

Transcripts contain your prompts, code and command output. Only share the zip with people you trust; this page keeps it on your machine.
